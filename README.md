# Part-2 (Server). Telegram Mini App 'Three-in-One'

### Имя Telegram Mini App: *@TgGroundBot*

```
Описание Приложения.
В приложении Telegram найдите бота с именем: **@TgGroundBot**
 - запустите бота нажатием кнопки 'Start' (альтернативно можно пользоваться Меню в закрепе, в нижней панели/меню Телеграма)
 - выйдет приветстве Вас по имени пользователя, а также появятся кнопки: "Инфо о приложении", "Открыть окно приложения"  
 - при нажатии на кнопку "Инфо о приложении" появится информация о доступных сервисах
 - при нажатии на кнопку "Открыть окно приложения" откроется окно приложения с возможностью выбора страниц 1-3 (1.Приватный чат, 2.Погода, 3.Прогноз)   
 - в приложении применены два разных протокола: ws (websocket), а также https
 - 1-я страница: "Приватный чат" реализован с применением протокола (webSocket), т.е. отображение сообщений в режиме real-time. 
   Второй пользователь видит сообщения только во время когда его оппонент одновременно находится в приложении. 
   При этом данные сообщения сохраняются только в локальной памяти на устройстве пользователей которые находятся в этот момент в переписке.  
 - 2-3 страницы: запросы Погоды и Прогноза происходят с применением протокола https  
   на странице "Погода" реализовано выпадающее меню с возможностью выбрать город. Текущая погода подгрузится для выбранного города.  
   на странице "Прогноз" реализована условно "бесконечная лента" подгрузки карточек о дальнейшей погоде (подгрузка ограничена платным сервисом API о погоде) 


 ```

##### Бэкэнд развернут на виртуальном сервере Nginx на Ubuntu

##### Basic stack: NodeJS, Express, Websocket, Telegram App Library, REST API; DevOps: Nginx, SSL

 ```
 Telegram Bot API: 'node-telegram-bot-api'  

 Weather service API address: https://api.weatherapi.com/  
 
 Endpoints:
 /api/weather - запрос текущей погоды  
 /api/forecast - запрос прогноза погоды  
 
 Chat endpoints:
 /new-messages - отправка нового сообщения  
 /get-messages - получение сообщения  

 ```
